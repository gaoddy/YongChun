# Runbook：终端命令执行

## 适用场景

- 需要在本机终端执行命令：构建、测试、静态检查、生成、迁移、检索、排查与状态查询。
- 本文只规定命令怎么执行；构建入口见[Make 构建入口](make.md)，工作区隔离见[Worktree 与分支](worktree.md)，失败定位见[问题排查](../problems/troubleshooting.md)。

## 前置读取

- [Worktree 与分支](worktree.md)

## 规则

### 执行环境

- 命令必须非交互执行：不接受 TTY 输入、分页器或确认提示，无 stdin 时能自行结束。反例：`vi`、`less`、`git rebase -i`、未加 `-y` 或 `--yes` 的包管理命令。
- 需要分页器的命令显式关掉分页，如 `GIT_PAGER=cat git log`、`PAGER=cat`。
- 不依赖交互式 shell 的别名、函数与提示符配置；命令内使用真实可执行文件与显式参数，跨 shell 时用 POSIX 写法。
- 环境变量在命令内一次性设置（`VAR=value 命令`）；不修改用户全局环境或 shell 配置文件。

### 工作目录

- 在任务 worktree 根目录执行命令；路径用绝对路径或先 `cd` 到该目录，不依赖上一条命令留下的目录。
- 命令写入文件时只写任务范围内的路径；临时文件写入 `output/` 或仓库忽略目录。

### 输出

- 单次命令输出限制在 8,000–16,000 字节；日志、测试与构建输出优先展示末尾内容。
- 输出可能超过上限时先重定向到 `output/` 下的日志文件，再 `tail` 读取末尾；不把完整输出带入上下文。
- 需要机器解析时使用稳定输出格式（`--porcelain`、`--json`、`-q`），不用彩色或本地化文案。

### 退出码

- 显式取码在管道之前完成：先用 `$?` 捕获命令退出码，再裁剪输出；不依赖 shell 方言的管道退出码变量。
- 常规写法：`out=$(命令 2>&1); rc=$?; printf '%s\n' "$out" | tail -n 20; echo "exit=$rc"`；输出可能很大时先重定向到 `output/` 下的日志文件，取 `$?` 后读末尾。
- 禁止 `命令 | tail; echo $?`（取到的是 `tail` 的退出码）以及 `${PIPESTATUS[0]}`、`$pipestatus[1]`、`$status` 等方言写法；`pipefail` 不能替代显式取码。
- 失败时保留原始退出码与末尾错误，不用 `|| true`、`2>/dev/null` 掩盖失败。

### 后台任务

- 预计超过单次命令合理等待时长的命令放到后台执行，用任务句柄或完成标记等待返回，不用 `pgrep`、`sleep` 轮询进程。
- 同一命令在后台运行时不再重复发起；查看进度时读任务输出的末尾内容。
- 后台命令失败时先读末尾错误与退出状态，再决定重跑或按[问题排查](../problems/troubleshooting.md)定位根因。
- 任务结束时停止遗留的后台进程，清理临时日志。

### 危险操作

- 删除、覆盖、`git reset --hard`、`git clean`、强制推送与批量改写等不可逆命令，执行前先列出目标与范围（`ls`、`git status`、`git diff`）；目标与预期不符时停止并报告。
- 不可逆命令只作用于任务范围内的路径与分支；需要扩大到任务范围外时先取得用户确认。
- 凭据、令牌与密钥不写入命令行明文参数；用环境变量或受限权限文件传入，不写入日志。

## 步骤

1. 确认命令用途、工作目录与预期退出状态；在任务 worktree 根目录执行。
2. 非交互执行命令；输出可能超过上限时重定向到 `output/` 日志文件。
3. 管道前用 `$?` 捕获退出码，再读末尾输出。
4. 预计超过等待时长的命令放后台，按任务句柄等待并读末尾输出。
5. 不可逆命令执行前列出目标并确认范围。
6. 失败时保留退出码与末尾错误，按[问题排查](../problems/troubleshooting.md)定位根因。
7. 清理临时日志与遗留后台进程。

## 验证

- 命令均在任务 worktree 内执行，工作目录显式指定。
- 执行过的命令退出码有记录；管道命令的退出码来自原命令而不是 `tail`。
- 单次输出不超过 16,000 字节；超大输出已落 `output/` 日志并只读末尾。
- 长命令后台执行并按任务句柄等待，未用 `pgrep`、`sleep` 轮询。
- 不可逆命令执行前列出了目标并确认范围，未超出任务范围。
- 临时文件与后台进程已清理。
