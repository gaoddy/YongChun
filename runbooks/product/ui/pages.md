# Runbook：页面设计

## 适用场景

- 新增或改版页面，调整页面结构、布局、状态或适配方式。

## 规则

### 结构与布局

- 先列页面清单：入口、返回方式、是否需要登录与权限；一个页面只承担一个主要任务。
- 结构按「页面骨架 → 区块 → 组件」分层，只保留必要层级；同层元素按阅读与操作顺序排列。
- 全局导航、页头、返回等由框架统一提供，页面不重复实现。
- 间距与尺寸使用 tokens 的刻度，不写死像素值。

### 页面状态

- 每个页面列全状态：加载中、空、错误、无权限、离线、达到限额；每种状态给出表现与出口（重试、返回、升级、刷新）。
- 列表页明确分页或加载更多、刷新方式、空态与错误态；详情页明确数据缺失时的退化表现。
- 同一时刻只呈现一种主状态，不叠加互相矛盾的提示。

### 适配

- 不同屏幕比例分别构图，不拉伸、不只靠中心裁切；检查主体取景与内容留白。
- 深浅色下保持结构一致，规则见[主题与视觉资源](theme.md)。
- 安全区、横竖屏与字体放大等系统设置下布局不重叠、不截断。

### 性能

- 首屏只加载必要数据；长列表分页或虚拟化，避免一次性渲染全量。
- 图片与资源按需加载并限制尺寸；控制重建范围，避免整页随单点状态刷新。

## 步骤

1. 列出受影响页面、入口、返回路径与权限要求。
2. 画出结构层级与区块划分，标注复用组件。
3. 列全页面状态与出口，标明数据来源。
4. 检查深浅色、屏幕比例与系统设置下的布局。
5. 标注性能敏感点：首屏、长列表、图片与资源。

## 验证

- 页面清单完整，每个页面有明确入口、返回与权限。
- 状态清单覆盖加载、空、错误、无权限、离线与限额，每种有出口。
- 深浅色结构一致，各屏幕比例无拉伸或裁切失真。
- 页面不重复实现导航与布局，间距尺寸来自 tokens。
