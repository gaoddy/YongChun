# Runbook：主题与视觉资源

## 适用场景

- 主题范围（单主题或深浅色）、主题切换、插画与背景等视觉资源的定义与调整。

## 前置读取

- [设计 tokens](tokens.md)

## 规则

- 项目事实声明了单主题（仅浅色或仅深色）时，按该主题设计与验证，不补另一套；声明与项目 UI 文档 `README.md` 的「主题与使用方式」保持一致，两处不一致时以项目事实为准并同步修正文档。
- 同一页面及相同业务状态在深色与浅色模式下保持一致的页面结构、组件层级、位置、尺寸、间距，以及滚动和固定行为；颜色、背景图等视觉资源可以随主题变化，不得因主题切换改变布局。
- 主题变化通过颜色、遮罩、渐变等视觉手段处理，保持页面结构和滚动行为一致。
- 插画与背景使用[设计 tokens](tokens.md)的颜色与形状语义；不得直接套用其他项目的画风、角色或场景。
- 新增视觉资源前确认现有令牌或资源能否表达；资源尺寸、比例、格式与命名统一，并登记使用场景。
- 视觉资源不替代布局结构；需要靠背景图撑出的层次应改为结构或令牌表达。

## 步骤

1. 确认涉及的页面、状态与主题范围（仅浅色、仅深色或两套）；项目事实已声明单主题时以其为准，不再逐次确认。
2. 检查令牌能否表达所需颜色与层次，不足时先在 tokens 中补齐。
3. 按主题范围给出表现：两套主题时按同一结构给出，不复制布局；单主题时只给该主题。
4. 明确插画、背景的来源、尺寸与使用场景。
5. 在主题范围内的各主题与各屏幕比例下检查结构与滚动行为。

## 验证

- 主题范围内的各主题下结构、层级、位置、尺寸、间距与滚动行为一致。
- 有主题切换时切换不改变布局，视觉资源随主题正确替换；单主题项目不涉及切换。
- 插画与背景使用[设计 tokens](tokens.md)的颜色与形状语义，来源与使用场景已登记。
- 无仅靠背景图或遮罩维持的布局层次。
