# Runbook：设计 tokens

## 适用场景

- 新增、调整或使用颜色、字体、间距、圆角、阴影、层级等视觉令牌。

## 前置读取

- [UI 设计](ui-design.md)
- [页面设计](pages.md)
- [组件设计](components.md)
- [图标](icons.md)

## 规则

### 定义

- tokens 是视觉取值的唯一来源；页面与组件不硬编码颜色、字号、行高、间距、圆角、阴影与层级。
- 按语义命名：颜色区分背景、文字、边框、状态；字体区分字号、行高、字重；间距使用固定刻度。
- 名称表达用途而非具体取值（如 `color-danger`、`space-md`），不出现 `red-500` 这类实现名。
- 深浅色是同一语义 token 的两套取值，不复制两套组件或两套布局。

### 使用与变更

- 新增 token 前先确认现有刻度能否表达；优先复用，避免近似值堆积。
- 不用任意值覆盖 token；确需例外时说明原因并登记，避免长期存在。
- 修改 token 前检查全部消费者，按影响验证页面与组件，不只看当前页面。
- token 定义在共享设计层并登记用途与取值；设计稿标注语义名而不是色值。

## 步骤

1. 确认需要的视觉维度与现有 token 能否覆盖。
2. 按语义命名新增或调整，给出深浅色取值。
3. 替换硬编码取值，检查全部使用处。
4. 在设计系统文档登记用途与示例。
5. 检查深浅色与各页面表现。

## 验证

- 页面与组件无硬编码视觉取值。
- token 命名语义化，刻度有限且无近似重复。
- 深浅色取值齐全，布局不随主题变化。
- 变更已覆盖全部消费者并登记。
