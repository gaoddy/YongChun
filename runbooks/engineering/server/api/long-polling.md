# Runbook：长轮询接口

## 适用场景

- 设计或调整长轮询接口的挂起时长、游标、空结果与并发连接规则。
- 通用规则与协议选择见[接口契约](contract.md)；新增或修改接口的实施步骤见[新增接口](../new-api.md)。

## 前置读取

- [接口契约](contract.md)

## 规则

- 长轮询只用于无法使用 [WebSocket](websocket.md) 或 [SSE](sse.md) 的近实时场景；能做长连接时不选长轮询。
- 请求携带游标或版本号，服务端只返回游标之后的数据；无新数据时挂起等待。
- 挂起时长上限小于网关、负载均衡与客户端超时；超时返回空结果（如 204 或空列表），不返回错误。
- 客户端收到空结果后立即重发，并加入退避与抖动，避免空转与同时重连。
- 同一游标重复请求返回相同结果，客户端按游标去重；游标过期时返回明确错误并给出重新拉取方式。
- 按用户与 IP 限制并发挂起连接数，连接释放与超时必须有上限。
- 挂起期间不持有数据库事务或连接；数据就绪通过通知或轻量查询检测。
- 长轮询只用于读操作，不用于提交写请求。

## 步骤

1. 确认实时性要求、客户端能力与为何不能使用长连接。
2. 定义游标、挂起时长、空结果与过期处理。
3. 定义并发连接限制与退避策略；偏离规范时写入版本 `technical.md` 并取得确认。
4. 按[新增接口](../new-api.md)完成契约、测试与文档。

## 验证

- 游标语义与重复请求结果一致，过期有明确错误。
- 挂起时长小于各级超时，空结果不当作错误。
- 并发挂起连接有限制，挂起期间不占用事务或连接。
- 不使用长轮询提交写请求。
