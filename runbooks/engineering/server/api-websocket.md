# Runbook：WebSocket 接口

## 适用场景

- 设计或调整 WebSocket 接口的握手鉴权、消息格式、心跳、重连与背压规则。
- 通用规则与协议选择见[服务端接口](api.md)；新增或修改接口的实施步骤见[新增接口](new-api.md)。

## 前置读取

- [服务端接口](api.md)

## 规则

- 握手时校验身份，不在连接建立后通过消息传递长期凭证；未认证连接在约定时间内断开。
- 消息使用统一信封，至少包含 `type`、`id`、`version` 与 `payload`；未知 `type` 忽略并记录，不断开连接。
- 心跳与超时：服务端主动 ping、客户端 pong，超时断开；客户端重连使用退避与抖动。
- 重连后按游标或序号恢复状态；明确消息是至少一次还是至多一次，重复消息可被客户端识别。
- 单连接内消息有序；发送队列有上限，超限时按约定丢弃或断开，不无限缓冲。
- 写明单条消息大小上限、分片方式与二进制编码格式。
- 连接数与消息速率按用户与 IP 限制；连接释放与空闲超时必须有上限。

## 步骤

1. 确认连接场景、双向消息方向与需要恢复的状态。
2. 定义握手鉴权、信封结构、错误消息、心跳与重连恢复规则。
3. 定义背压、消息大小、分片与编码；偏离规范时写入版本 `technical.md` 并取得确认。
4. 按[新增接口](new-api.md)完成契约、测试与文档。

## 验证

- 握手鉴权、心跳、超时与重连恢复规则完整。
- 未知消息类型可安全忽略，重复消息可识别。
- 背压与消息大小上限明确，无无限缓冲。
- 连接数与速率限制可执行。
