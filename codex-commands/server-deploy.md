按 yongchun 插件的 runbook 执行用户请求。

1. 定位插件根目录：Claude Code 为插件根（环境变量 CLAUDE_PLUGIN_ROOT）；Codex 为插件安装目录，位于 `~/.codex/plugins/cache` 下。
2. 读取并按内容执行 `runbooks/delivery/server-deploy.md`。
3. 先确认目标环境、版本号与产物来源；未指明环境时先问清，不默认生产。
4. 只发布已合入基线分支的提交，任务分支不直接部署。
5. 发布前核对必需配置与 Secret 已就绪、迁移能被仍在运行的旧实例兼容；任一不满足时停止并报告，不进入滚动更新。
6. 破坏性变更拆成两步发布：先兼容读，再切换写；回滚只回退代码，不回退已执行的迁移。
7. 新实例通过 `/readyz` 后才接流量，确认旧实例在优雅停机窗口内退出，再按可观测性看板观察错误率与延迟。
8. 记录版本、提交、变更内容、迁移项与回滚方式。

完成判定：目标环境实例全部就绪且镜像与版本一致，发布期间无请求失败，关键指标回到基线，发布记录已写入。
